# AGENTS.md

Guidance for AI agents working in the Syndes frontend (Next.js app).

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on `DamionAzure/Syndes` via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the frontend root. See `docs/agents/domain.md`.
